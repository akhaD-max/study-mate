# Поиск проектов по направлению, роли и открытому набору

Ветка: `feat/009-project-search` → `main`.

Каталог позволяет найти проекты по названию/описанию, направлению и должности из БД. При включённом фильтре открытого набора выбранная роль должна быть открыта и иметь свободное место; занятость считается по членству, pending-заявки места не занимают. Отключение фильтра показывает все статусы. Поиск и фильтры выполняются в PostgreSQL до пагинации.

Интерфейс приведён к структуре Figma «02»: поиск сверху, боковые фильтры, список карточек. Добавлены валидация query-параметров, ошибки HTML/HTMX, сохранение URL, сброс и недоступный «Формат участия» до появления поля в БД. Главная и существующие переходы регистрации/входа используют тот же каталог.

Новый одиночный параметр `role` содержит название должности до 100 символов и сравнивается без учёта регистра. Общего справочника должностей нет; варианты собираются из `ProjectRole` без повторов регистра. Расширение общего контракта передаётся Владу. Модели, миграции, зависимости, настройки и корневые URL не меняются.

Проверено: полный pytest на PostgreSQL — 132 passed; после финального уточнения аргументов selector и нормализации контекста — 23/23 теста каталога и поиска. Полный Windows Ruff, pip check, Django check, makemigrations --check --dry-run, migrate --check и git diff --check успешны. Docker пересобран.

В браузере проверены роль, пустая выдача, HTTP 400 через HTMX, сброс, login/next и адаптивность на 390 px. Регистрация, вход и полный сценарий заявки проверены автоматизированно. Сетевой обрыв/таймаут/5xx вручную не имитировались.

Подробные объяснения, команды и ограничения: `docs/009-project-search.md`. Публикация PR и ревью — Данила.
