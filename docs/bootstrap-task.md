# Задача: окружение, каркас Django и Docker

- Поручение: клонировать study-mate в текущую папку, установить точные версии,
  создать Django-проект без дополнительных приложений и проверить Docker Compose.
- Ответственный за постановку и передачу на ревью: владелец текущей задачи;
  исполнитель: Codex.
- Ветка: `feature/django-docker-bootstrap`, база: `origin/main`.
- Приёмка: Python 3.13.16 в локальной `.venv`, установка исходного
  `requirements.txt`, проект `config`, PostgreSQL 17.11, сборка Compose,
  успешные проверки Django и HTTP-ответ корневой страницы.
- Файлы: `manage.py`, `config/`, `templates/`, `static/vendor/`, `Dockerfile`,
  `compose.yaml`, `.env.example`, `.gitignore`, `.dockerignore`, `scripts/`, `docs/`.
- Зависимости: доступ к Python.org, PyPI, Docker Hub, запуск Docker Desktop.
- `requirements.txt` и `AGENTS.md` сохраняются. README заменён краткой
  инструкцией, утверждённой владельцем задачи; подробная инструкция и отчёт
  находятся в `docs/`.
- Доменные приложения, кастомный пользователь и общая схема данных в эту
  задачу не входят. Первые рабочие миграции следует выполнять после решения
  о модели пользователя. Проверка миграций возможна в отдельной проверочной БД.
- Версии Ruff/pytest для команды ещё не утверждены техлидом. Зависимости
  разработки в общий manifest без согласования не добавляются.
