# Каталог проектов: интеграция макета

## План и критерии приёмки

- Цель: заменить заглушку каталога предоставленным оформлением, уменьшить hero и убрать мотивационную плашку.
- Данные: только Project, Category и ProjectRole из БД; без демонстрационных карточек и автоматического наполнения.
- Ветка: arena/55ba1125-study-mate. Исполнитель: агент Arena по поручению владельца задачи; ревью — владелец задачи.
- Модули: main/views.py, projects/templates/projects/, static/css/catalog.css, tests/projects/test_catalog.py.
- Контракты: существующий URL main:catalog и параметры direction (slug Category), q, sort, page. HTMX target #catalog-content. Базовый шаблон и модель не изменяются.
- Каталог показывает проекты со статусом OPEN; категории из БД. Серверная фильтрация, сортировка, пагинация, полная страница и HTML-фрагмент; обычные GET работают без JS.
- Зависимости: существующие Django auth, ORM, локальные HTMX и Inter. Миграции и новые библиотеки не требуются.

## Реализация

- Запрос ограничен статусом OPEN, данные автора/категории загружаются через select_related, открытые роли с занятостью — через Prefetch. Количество участников вычисляется в ORM; пагинация по 12 карточек. Четыре запроса на страницу независимо от числа карточек (проверка добавлена в интеграционные тесты).
- Категории берутся из Category, а не из фиксированного списка. Поиск по названию и описанию, параметры фильтров сохраняются в ссылках пагинации. Сортировки: новые/старые, больше/меньше участников. «Популярность» не имитируется: в модели нет соответствующего показателя.
- HTMX возвращает #catalog-content целиком, включая выбранную категорию, поиск, сортировку и счётчик; URL обновляется. При HX-History-Restore-Request возвращается полная страница. Ответы имеют Vary для этих заголовков.
- Макет использует существующие локальные Inter и HTMX, без Tailwind/CDN. Высота desktop hero определяется компактными отступами 40px и заголовком до 56px вместо больших отступов и 76px исходного макета. Убрана нижняя мотивационная фраза.
- Отдельного маршрута карточки проекта пока нет. Вместо битых ссылок добавлены нативные details с описанием и реальными ролями/местами. Их можно заменить ссылкой при появлении страницы проекта. Ссылки на ещё не реализованные «Профиль» и «Мои заявки» не добавлены; гостю доступен вход, пользователю — его инициалы и POST-выход с CSRF.
- Без JavaScript фильтры отправляются кнопкой «Найти», пагинация и раскрытие описаний работают нативно.
