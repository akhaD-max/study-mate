# Демо-данные для поиска

`seed_demo` сохраняет прежние четыре проекта и добавляет десять новых. На исходных данных всего 14 проектов, из них 13 попадают в каталог с открытым набором. Размер страницы — 12, поэтому есть вторая страница.

## Загрузка

После обновления исходников пересоберите образ и запустите команду с вашим прежним демо-паролем:

```powershell
docker compose build web
docker compose up -d --wait db
docker compose run --rm web python manage.py migrate
docker compose run --rm web python manage.py seed_demo --password "ВАШ_ДЕМО_ПАРОЛЬ"
docker compose up -d --wait web
```

Учётные записи остаются прежними: `author@studymate.local`, `student1@studymate.local`, `student2@studymate.local`. Пароль всех трёх обновляется на переданный в команде. Запуск можно повторять: дубли не создаются. Существующие новые карточки, роли и состав команды не сбрасываются; полный сброс состояния не предусмотрен.

## Что проверить вручную

Следующие ожидания относятся к исходным демо-данным без дополнительных проектов и ручных изменений. Условия каждого примера начинайте со сброса фильтров.

| Действие | Ожидаемый результат |
| --- | --- |
| Пустой поиск, открытый набор включён | 13 проектов, 12 на первой странице и 1 на второй |
| Выключить открытый набор | 14 проектов; появляется «Аналитика вовлечённости онлайн-курсов» |
| Искать `Python`, `python`, затем ` Python ` | Один и тот же набор из 5 проектов: Python Lab, Исследование интерфейсов, Обмен учебниками, Планировщик встреч, Мониторинг воздуха |
| `Python` + направление «Дизайн» | Только «Исследование интерфейсов кампуса», совпадение по описанию |
| `Python` + роль «Backend-разработчик», открытый набор включён | Python Lab и Мониторинг воздуха. Обмен учебниками и Планировщик встреч не подходят: их Backend-роль занята или закрыта |
| Тот же поиск и роль, открытый набор выключен | 4 проекта: предыдущие два, Обмен учебниками и Планировщик встреч |
| Искать `РОБОТ`, затем `робот` | Только «Робот помощник в лаборатории» |
| Искать `чат` | Только «Чат-бот для первокурсников» |
| Искать `Аналитика`, затем выключить открытый набор | Сначала пусто, затем один проект «Аналитика вовлечённости онлайн-курсов» |
| Искать `несуществующий-проект-8472` | Пустое состояние со сбросом фильтров |
| На пустом поиске открыть страницу 2, обновить страницу и вернуться назад | Страница и условия восстанавливаются; проекты между страницами не дублируются |

Эти примеры позволяют проверить реальный каталог, но не заменяют точные P01–P10 и Q01–Q13 из старых тест-кейсов: у них другой состав и ожидаемые счётчики. При использовании демо-данных укажите это в QA-отчёте и сверяйтесь с таблицей выше. Ручные результаты в этом документе не утверждаются.
