# Заголовок PR

Добавить MVP профиля студента с навыками и желаемой ролью

Ветка: `feat/025-user_profile` → `main`. Публикация — владельцем задачи.

## Изменения

После регистрации студент попадает на заполнение профиля, сохраняет вуз,
специальность, курс и 1–15 навыков, при желании — имя, специализацию и
описание. Данные хранятся в PostgreSQL. Просмотр своего и чужого профиля
требует входа; редактор всегда работает с пользователем из сессии.
В карточку не выводятся email, служебные поля аккаунта и заявки.

Добавлены серверная валидация с сохранением ввода, транзакционное
сохранение, пустое состояние, заглушка аватара, счётчик описания и
предупреждение при уходе с несохранёнными изменениями.
Страницы профиля — HTML без CSS. «Профиль» появился рядом с «Каталогом»,
«Мой профиль» в меню активен; имена кандидатов, авторов и участников
ведут в карточки. В двух существующих тестах обновлены ожидаемые
переход и состояние ссылки; тесты не запускались.

URL: `/profile/`, `/profile/edit/`, `/profile/<UUID>/`;
совместимый префикс `/accounts/profile/` использует те же обработчики.

## Миграции и зависимости

`accounts.0002_profile_fields` добавляет поля User, общие справочники
Skill/Specialization, связи и CHECK курса. `0003_profile_catalogs` добавляет
18 специализаций из MVP и 35 стартовых навыков. Начальные миграции
не переписываются. Новых библиотек и изменений requirements нет.
